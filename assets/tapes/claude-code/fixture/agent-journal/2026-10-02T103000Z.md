retry(fn, attempts) runs fn until it resolves and throws the last error. Kept the API small on purpose.

Left out backoff: the only caller retries a local file lock, which frees up within milliseconds, so waiting longer would only slow it down. Backoff would also add two options that nobody uses yet. Add it when a caller talks to a rate-limited service.
