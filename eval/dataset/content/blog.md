# blog

blog is the user's personal technical blog, a static site in a git repository. The user writes the posts; the agent helps with the site, the drafts and the images.

## Stack

Astro, Markdown posts with front matter, Tailwind, images optimized at build time, an RSS feed, a comment form through a small serverless function, hosted on Netlify.

## Timeline (days relative to today, negative is the past)

- -1095 to -900: the move from an older static generator to Astro, the theme, the RSS feed, the redirects of old URLs.
- -900 to -600: posts about queues and backpressure, about Postgres indexes, about the AI SDK; the image sizes and lazy loading, syntax highlighting, the comment form and its spam filter.
- -600 to -380: fewer posts: a post about a homelab backup setup, a dark mode, dependency updates, a draft that never got published. No work after day -380.

## Rules for the text

Images in posts are PNG, JPEG or WebP. Never write about GIFs.

## Branches

None. Every session runs in the main checkout.
