# dotfiles

dotfiles is the user's configuration of their Mac in a folder that is not a git repository, so the entries have no project. The agent edits the shell, the editor, the terminal and the tools, and sometimes helps with other small things on the machine.

## Stack

zsh with a small prompt of its own, git aliases, Neovim and later Zed as the editor, tmux, Ghostty as the terminal (iTerm2 before about day -600), Homebrew with a Brewfile, mise for the versions of Node and Python, a backup script with rsync, macOS defaults set by a script.

## Timeline (days relative to today, negative is the past)

- -1095 to -700: the zsh prompt, git aliases, the Neovim config, the tmux config, the Brewfile.
- -700 to -300: the move to Ghostty, the move from nvm to mise, the editor keymap in Zed next to Neovim, the backup script, SSH keys in the 1Password agent.
- -300 to -2: small changes: a slow shell start, git config for signing commits, tmux key bindings, a new Mac set up from the scripts, the terminal font (JetBrains Mono for most of this time; the change to another font on day -1 is a key entry).
